# Журнал изменений (CHANGELOG)

Все значимые изменения в проекте **Repin 2.0** будут фиксироваться в этом файле.

## [2.0.1] — 2026-05-02
### Добавлено
- Новый раздел **Галерея (Showcase)** на лендинге с примерами генерации.
- Продвинутая **SVG-анимация GAN** в Hero-секции сайта.
- Файл лицензии **MIT**.
- Журнал изменений (**CHANGELOG.md**) на русском языке.

### Изменено
- Обновлен `README.md`: добавлены бейджи, ссылки на живое демо и галерея.
- Синхронизированы метаданные репозитория на GitHub (описание, теги, ссылка на сайт).

## [2.0.0] — 2026-04-30
### Добавлено
- Полностью новый CLI-интерфейс на базе библиотеки `rich`.
- **Debug Menu**: инструменты для бенчмаркинга и инспекции модели.
- Поддержка Intel GPU (`torch.xpu`) и точности `bfloat16`.
- Автоматическое масштабирование (Upscale) артов в 8 раз.
- Интерактивный лендинг в стиле **Glassmorphism**.

### Исправлено
- Исправлено выравнивание таблиц в терминалах Windows/Unix.
- Локализованы все системные сообщения в CLI.
