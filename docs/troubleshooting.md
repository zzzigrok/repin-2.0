## ❌ Ошибки запуска

### Файл весов не найден

**Симптом:**
```
❌ Ошибка: Файл весов 'repin_weights.pth' не найден. Сначала обучите модель!
```

**Причина:** Вы пытаетесь сгенерировать изображения без обученной модели.

**Решение:**
1. Выберите пункт **[ 1 ]** в главном меню.
2. Введите количество эпох (рекомендуется минимум 20 для видимого результата).
3. Дождитесь завершения обучения.
4. Попробуйте генерацию снова.

> [!NOTE]
> Файл `repin_weights.pth` создаётся автоматически после первого завершённого обучения. Его размер составляет ~2.1 МБ.

### Ошибка при импорте модулей

**Симптом:**
```python
ModuleNotFoundError: No module named 'torch'
# или
ModuleNotFoundError: No module named 'rich'
```

**Причина:** Не установлены зависимости или активировано неправильное окружение.

**Решение:**
```bash
# Проверьте, какой Python используется
python --version
which python  # Linux/macOS
where python  # Windows

# Установите зависимости
pip install torch torchvision rich

# Если используете виртуальное окружение:
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install torch torchvision rich
```

### Ошибка `KeyboardInterrupt`

**Симптом:**
```
Программа прервана пользователем.
```

**Причина:** Нажата комбинация `Ctrl+C` во время работы программы.

**Решение:** Это штатное поведение. Программа корректно обрабатывает прерывание. Однако, если обучение было прервано, веса **не сохраняются**. Нужно запустить обучение заново.

> [!WARNING]
> **Потеря прогресса.** При прерывании обучения через `Ctrl+C` все промежуточные результаты текущей сессии теряются. Веса сохраняются только по завершении всех эпох.

## 🐢 Проблемы производительности

### Медленное обучение (CPU)

**Симптом:** Каждая эпоха занимает более 40 секунд.

**Диагностика:**

| Проверка | Команда | Ожидаемое |
| :--- | :--- | :--- |
| Потоки PyTorch | `python -c "import torch; print(torch.get_num_threads())"` | 6 |
| Модель CPU | `python -c "import torch; print(torch.cpu.is_available())"` | True |
| XPU доступен? | `python -c "import torch; print(hasattr(torch, 'xpu') and torch.xpu.is_available())"` | True/False |

**Решения:**

1. **Увеличить число потоков CPU.** Откройте `cli.py`, найдите строку:
   ```python
   torch.set_num_threads(6)
   ```
   Измените значение на количество физических ядер вашего процессора. Узнать количество ядер:
   ```bash
   # Windows (PowerShell):
   (Get-CimInstance -ClassName Win32_Processor).NumberOfCores
   # Linux:
   nproc --all
   ```

2. **Используйте XPU.** Если у вас GPU Intel (Arc, Flex), установите [Intel Extension for PyTorch](https://github.com/intel/intel-extension-for-pytorch).

3. **Уменьшить число эпох.** Для тестирования достаточно 10–20 эпох.

### Высокое потребление RAM

**Симптом:** Система замедляется во время обучения, используется 4+ ГБ RAM.

**Решение:** Уменьшите `batch_size` в функции `train_model()`:
```python
batch_size = 64   # Вместо 128 по умолчанию
```

## 📦 Проблемы с зависимостями

### Конфликт версий PyTorch

**Симптом:**
```
RuntimeError: Expected all tensors to be on the same device
```

**Решение:** Обновите PyTorch до последней стабильной версии:
```bash
pip install --upgrade torch torchvision
```

### Старая версия Python

**Симптом:** Синтаксические ошибки при запуске.

**Решение:** Repin 2.0 требует Python 3.8+. Проверьте версию:
```bash
python --version
```

### Полная таблица зависимостей

| Пакет | Минимальная версия | Назначение |
| :--- | :--- | :--- |
| `torch` | 2.0.0 | Нейронные сети, тензоры, autograd |
| `torchvision` | 0.15.0 | Датасеты (MNIST), утилиты изображений |
| `rich` | 13.0.0 | Терминальный UI (панели, прогресс-бары, таблицы) |

## 📟 Проблемы с отображением CLI

### Кракозябры вместо символов

**Симптом:** В меню отображаются знаки `???`, `â–ˆ` или другие нечитаемые символы.

**Причина:** Терминал не поддерживает UTF-8 или использует несовместимый шрифт.

**Решение для Windows:**
```powershell
# Установить кодировку UTF-8 в текущей сессии PowerShell
[Console]::OutputEncoding = [Text.Encoding]::UTF8
$env:PYTHONIOENCODING = "utf-8"

# Или установить переменную окружения глобально:
[System.Environment]::SetEnvironmentVariable("PYTHONIOENCODING", "utf-8", "User")
```

**Рекомендуемые шрифты** для корректного отображения блочных символов:
- **Cascadia Code** (поставляется с Windows Terminal)
- **JetBrains Mono**
- **Fira Code**
- **Consolas** (встроенный в Windows, поддержка частичная)

### Цвета не отображаются

**Симптом:** Текст монохромный, нет цветовой стилизации.

**Причина:** Терминал не поддерживает ANSI escape sequences.

**Решение:**
- Используйте **Windows Terminal** вместо классического `cmd.exe`
- В **VS Code**: убедитесь, что терминал использует профиль PowerShell
- В **PyCharm**: включите опцию `Run → Edit Configurations → Emulate terminal in output console`

### Прогресс-бар мерцает или скачет

**Симптом:** Вместо плавного прогресса — хаотичное обновление строк.

**Причина:** Слишком узкий терминал или неподдерживаемый эмулятор.

**Решение:** Увеличьте ширину терминала минимум до **100 символов**. В Windows Terminal: правый клик на заголовок → Настройки → Профиль → Начальный размер.

## 🧠 Проблемы качества генерации

### Генерируется шум (цифры не узнаваемы)

**Симптом:** Вместо цифр — абстрактные пятна или серый шум.

**Причина:** Модель недостаточно обучена.

**Решение:**
- Обучите модель минимум на **30–50 эпохах**
- Следите за значениями loss: G_Loss должен стабилизироваться в диапазоне 1.0–2.0

| G_Loss | D_Loss | Интерпретация |
| :--- | :--- | :--- |
| > 5.0 | < 0.1 | ❌ Дискриминатор доминирует. Обучение провалилось. |
| 1.0–2.0 | 0.5–0.8 | ✅ Нормальный баланс. Модель учится. |
| < 0.5 | > 3.0 | ⚠️ Генератор доминирует. Возможно mode collapse. |

### Все цифры выглядят одинаково (Mode Collapse)

**Симптом:** Генератор создаёт только одну или две цифры (например, только «1» и «7»).

**Причина:** Mode collapse — классическая патология GAN.

**Решение:**
1. Удалите `repin_weights.pth` и обучите модель заново.
2. Попробуйте увеличить `latent_size` (например, 100 вместо 64).
3. Увеличьте `weight_decay` до `5e-4` для более сильной регуляризации.

### Цифры размытые после апскейлинга

**Симптом:** Изображение 224×224 выглядит мыльным.

**Причина:** Если вы изменили метод интерполяции на `bilinear` или `bicubic`.

**Решение:** Убедитесь, что в `generate_images()` используется `mode='nearest'`:
```python
generated_images = F.interpolate(generated_images, scale_factor=8, mode='nearest')
```

## 💾 Проблемы с файлами и данными

### MNIST не скачивается

**Симптом:**
```
urllib.error.URLError: <urlopen error [Errno 11001] getaddrinfo failed>
```

**Причина:** Нет доступа к интернету или заблокирован доступ к серверам MNIST.

**Решение:**
1. Проверьте подключение к интернету
2. Если вы за прокси, настройте переменные окружения:
   ```bash
   set HTTPS_PROXY=http://proxy:port
   set HTTP_PROXY=http://proxy:port
   ```
3. Скачайте MNIST вручную и распакуйте в `data/MNIST/raw/`

### Папка `generated_art/` не создаётся

**Симптом:** Ошибка `FileNotFoundError` при сохранении.

**Причина:** Нет прав на создание директории.

**Решение:** Создайте папку вручную:
```bash
mkdir generated_art
```

### Файл весов повреждён

**Симптом:**
```
RuntimeError: PytorchStreamReader failed reading
```

**Причина:** Файл `repin_weights.pth` повреждён (неполная запись, ошибка диска).

**Решение:**
1. Удалите повреждённый файл: `del repin_weights.pth`
2. Обучите модель заново.

## ⚡ Проблемы с XPU/GPU

### XPU не определяется

**Симптом:** В меню отображается `Device: CPU`, хотя у вас есть Intel GPU.

**Диагностика:**
```python
import torch
print(f"Версия PyTorch: {torch.__version__}")
print(f"XPU доступен: {hasattr(torch, 'xpu') and torch.xpu.is_available()}")
if hasattr(torch, 'xpu') and torch.xpu.is_available():
    print(f"Имя GPU: {torch.xpu.get_device_name(0)}")
    print(f"Количество GPU: {torch.xpu.device_count()}")
```

**Решение:**
1. Установите [Intel Extension for PyTorch](https://github.com/intel/intel-extension-for-pytorch)
2. Обновите драйверы Intel GPU
3. Убедитесь, что PyTorch собран с поддержкой XPU

### Ошибка Out of Memory на XPU

**Симптом:**
```
RuntimeError: XPU out of memory
```

**Решение:** Уменьшите batch size:
```python
batch_size = 64  # Вместо 128
```

## 🆘 Диагностический чеклист

Если что-то не работает, пройдитесь по этому чеклисту:

```
[ ] Python 3.8+ установлен и доступен в PATH
[ ] pip install torch torchvision rich — все пакеты установлены
[ ] Вы находитесь в корневой директории проекта (где лежит cli.py)
[ ] Терминал поддерживает UTF-8 и ANSI-цвета
[ ] Достаточно свободной RAM (>2 ГБ)
[ ] Достаточно места на диске (>500 МБ)
[ ] Если нужна генерация — файл repin_weights.pth существует
[ ] Если нужен MNIST — есть доступ к интернету (только при первом запуске)
```
