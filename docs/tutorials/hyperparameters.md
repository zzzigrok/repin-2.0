## 1. Что такое гиперпараметры?

**Гиперпараметры** — настройки, задаваемые **до начала обучения** и не обновляемые автоматически (в отличие от весов нейросети). Они определяют *как* модель учится.

> [!NOTE]
> Подбор гиперпараметров — часто вопрос эксперимента. Идеальной формулы не существует, но есть проверенные эвристики, описанные ниже.

---

## 2. Карта гиперпараметров

| Гиперпараметр | Текущее значение | Где задаётся | Категория |
| :--- | :--- | :--- | :--- |
| `latent_size` | 64 | Глобальная переменная | Архитектура |
| `hidden_size` | 256 | Глобальная переменная | Архитектура |
| `batch_size` | 128 | `train_model()` | Обучение |
| `lr` | 0.0002 | `train_model()` | Оптимизатор |
| `betas` | (0.5, 0.999) | `train_model()` | Оптимизатор |
| `weight_decay` | 1e-4 | `train_model()` | Регуляризация |
| `num_epochs` | 50 (default) | Ввод пользователя | Обучение |

---

## 3. Латентная размерность (latent_size)

Размерность вектора шума, из которого Генератор создаёт изображение. Текущее значение: **64**.

```python
latent_size = 64  # строка ~32 в cli.py
```

| Значение | Эффект |
| :--- | :--- |
| **16–32** | Мало разнообразия, но модель проще и быстрее |
| **64** ✅ | Баланс разнообразия и стабильности |
| **128–256** | Больше разнообразия, труднее обучить |

> [!WARNING]
> При изменении `latent_size` старые веса (`repin_weights.pth`) станут несовместимы! Необходимо обучить модель заново.

---

## 4. Размер скрытых слоёв (hidden_size)

Базовый размер скрытых слоёв. Определяет «ёмкость» модели. Текущее значение: **256**.

| Значение | Параметры (G + D) | Эффект |
| :--- | :--- | :--- |
| **64** | ~70K | Очень лёгкая, мало деталей |
| **128** | ~270K | Для быстрых экспериментов |
| **256** ✅ | ~1.1M | Баланс качества и скорости |
| **512** | ~4.2M | Медленнее, для сложных данных |

> [!CAUTION]
> Удвоение `hidden_size` ≈ учетверение параметров и времени обучения.

---

## 5. Размер батча (batch_size)

Количество изображений за одну итерацию. Текущее значение: **128**.

```python
# В функции train_model():
batch_size = 128
```

| Значение | RAM | Стабильность | Скорость |
| :--- | :--- | :--- | :--- |
| **32** | ~0.5 ГБ | Шумные градиенты | Много батчей |
| **64** | ~1 ГБ | Хороший баланс | Хорошая |
| **128** ✅ | ~1.5 ГБ | Стабильные градиенты | Оптимально |
| **256** | ~3 ГБ | Очень стабильно | Медленные батчи |

---

## 6. Learning Rate (lr)

Скорость обучения — **самый важный** гиперпараметр. Текущее значение: **0.0002**.

| Значение | Эффект | Риск |
| :--- | :--- | :--- |
| **0.00005** | Медленное, стабильное | Может не сойтись |
| **0.0001** | Консервативное | Долго, но надёжно |
| **0.0002** ✅ | Стандарт для GAN | Проверенное значение |
| **0.001** | Быстрое | Нестабильность, осцилляции |
| **0.01** | Слишком быстрое | ❌ Модель не сходится |

### Разный LR для G и D

```python
d_optimizer = torch.optim.AdamW(D.parameters(), lr=0.0002)
g_optimizer = torch.optim.AdamW(G.parameters(), lr=0.0001)  # G медленнее
```

> [!TIP]
> Если D доминирует (D_Loss → 0), уменьшите его lr или увеличите lr Генератора.

---

## 7. Weight Decay

L2-регуляризация — штраф за большие веса. Текущее значение: **1e-4**.

| Значение | Эффект |
| :--- | :--- |
| **0** | Нет регуляризации, риск переобучения |
| **1e-5** | Минимальная |
| **1e-4** ✅ | Стандарт для GAN |
| **1e-3** | Сильная, может мешать |
| **1e-2** | Слишком сильная |

> [!NOTE]
> В AdamW weight decay отделён от адаптивного шага — это делает регуляризацию более предсказуемой.

---

## 8. Количество эпох

Сколько раз модель проходит через весь датасет. 1 эпоха = 468 батчей.

| Эпохи | Статус | Время (CPU i5) |
| :--- | :--- | :--- |
| 1–10 | Недообучение | ~3 мин |
| 20–30 | Начало обучения | ~12 мин |
| **30–50** ✅ | Оптимум | ~25 мин |
| 50–100 | Улучшение | ~50 мин |
| 100+ | Риск mode collapse | 1+ час |

---

## 9. Моменты оптимизатора (betas)

Коэффициенты скользящего среднего. Текущее значение: **(0.5, 0.999)**.

**Почему beta1 = 0.5, а не стандартные 0.9?**

В GAN распределение данных для Дискриминатора постоянно меняется (сгенерированные изображения улучшаются). Высокая «инерция» (beta1=0.9) заставляет оптимизатор помнить устаревшие градиенты. Низкий beta1=0.5 делает его более «отзывчивым».
