## 🌟 Почему это интересно?

Repin 2.0 — это не просто скрипт, это **мост между классическим машинным обучением и генеративным искусством**. Эти туториалы помогут вам понять, как шум превращается в узнаваемые образы.

### Что вы узнаете

```mermaid
flowchart LR
    NOISE["🎲 Случайный шум"]
    GAN["🧠 GAN обучение"]
    ART["🎨 Цифровое искусство"]

    NOISE -->|Быстрый старт| GAN
    GAN -->|Обучение + Гиперпараметры| ART

    style NOISE fill:#1a1a2e,stroke:#00e5ff,color:#fff
    style GAN fill:#2e2e1a,stroke:#ffcc00,color:#fff
    style ART fill:#1a2e1a,stroke:#00ff88,color:#fff
```

### Рекомендуемый порядок прохождения

| Путь | Для кого | Туториалы |
| :--- | :--- | :--- |
| **Быстрый** | Хочу увидеть результат сейчас | 1 → 4 |
| **Стандартный** | Хочу понять и запустить | 1 → 2 → 4 |
| **Полный** | Хочу разобраться во всём | 1 → 2 → 3 → 4 |
