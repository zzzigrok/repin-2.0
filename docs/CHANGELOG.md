## [2.0.0] — 2026-04-30

### 🚀 Добавлено
- **Art Upscaling** — увеличение изображений 28×28 → 224×224 методом Nearest Neighbor для эффекта пиксель-арта.
- **Смешанная точность (bfloat16)** — автоматическое использование `torch.autocast` для ускорения обучения и генерации.
- **Поддержка Intel XPU** — автоматическое определение и использование `torch.xpu` при наличии совместимого GPU Intel.
- **Выбор batch size** — возможность генерировать 1, 16, 32 или 64 изображений за раз.
- **Выбор количества эпох** — пользователь может задать количество эпох при каждом обучении.
- **Красивый CLI на Rich** — полный редизайн интерфейса:
  - ASCII-арт логотип с цветовым градиентом
  - Двойной прогресс-бар (эпохи + батчи) с ETA
  - Живое отображение D_Loss и G_Loss
  - Анимированный спиннер при генерации
- **Документация** — полный набор технической документации:
  - Архитектура с Mermaid-диаграммами
  - Руководство по использованию CLI
  - Справочник API
  - Туториалы (быстрый старт, обучение, гиперпараметры, генерация)
  - Troubleshooting с диагностикой
- **Метки времени** — все генерации сохраняются с уникальными метками `YYYYMMDD_HHMMSS`.

### 🔄 Изменено
- Оптимизатор переведён с Adam на **AdamW** (decoupled weight decay).
- `beta1` изменена с 0.9 на **0.5** для стабильности GAN-обучения.
- Добавлен `weight_decay=1e-4` для регуляризации.
- Используется `zero_grad(set_to_none=True)` для более быстрого обнуления градиентов.
- Передача данных на устройство с `non_blocking=True`.
- Логотип обновлён до блочного ASCII-арта с градиентом.

### 🗑 Удалено
- Зависимость от `matplotlib` — вся визуализация через `rich`.
- Ручной выбор устройства — теперь определяется автоматически.

## [1.0.0] — 2026-04-17

### 🚀 Добавлено
- Первая версия GAN для генерации цифр MNIST.
- Базовый CLI-интерфейс (без `rich`).
- Генератор: MLP (64 → 256 → 512 → 784).
- Дискриминатор: MLP (784 → 512 → 256 → 1).
- Обучение на 50 эпохах с BCELoss + Adam.
- Сохранение весов в `repin_weights.pth`.
- Генерация батча из 16 изображений.
- Лицензия MIT.
